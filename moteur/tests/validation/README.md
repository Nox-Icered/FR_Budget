# Tests de validation

Un test par levier et par millésime de référence. Chaque test porte le marqueur `validation` et nomme :

- la référence officielle ou académique (document, page, tableau) ;
- son millésime ;
- la tolérance appliquée (±10 % sur le rendement à 1 an pour un levier paramétrique).

Un test de validation n'est jamais modifié pour faire passer le code : l'écart est examiné et rapporté tel quel.
