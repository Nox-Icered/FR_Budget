# Fiches

Une fiche par levier ou module. Elle se lit sans ouvrir le code : question posée, réglages, méthode, données, hypothèses, validation, limites, journal. Modèle : [`_modele.md`](_modele.md).

L'en-tête de chaque fiche indique le levier (`levier:`, identifiant de `registres/leviers.yaml`) ou le module (`module:`) qu'elle décrit. La vérification des registres contrôle que le levier existe.

| Fiche | Objet | Statut |
|-------|-------|--------|
| [`cascade_salaire.md`](cascade_salaire.md) | Module : cascade du salaire d'un ménage type | En cours (12 comparaisons validées) |
| [`tva.md`](tva.md) | Levier TVA | Méthode proposée, données à réunir |
